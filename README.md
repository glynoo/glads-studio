# GLADS Studio · Golden20 人工复核

这是 GLADS v1.0 交付包的**本地可运行人工复核系统**。它读取交付包中的 20 个 Golden20 案例，展示原图、精确融合掩码和 58 张 Big-LaMa 参考候选，支持比较、定位批注、人工决策与导出。它不会训练模型，也不会对新图生成修复候选。

## 运行

需要 Node.js 20.19+、Python 3.9+，以及同级目录 `GLADS_v1.0交付包/GLADS-03-Golden20-Reference-v1.0_20260810.zip`。无需 GPU、账户或模型服务。

```sh
cd glads-workbench
npm install
npm run dev
```

打开终端显示的本机地址（通常是 `http://127.0.0.1:5173/#/workbench`）。首次启动会核对 Golden20 压缩包的 SHA256；如果文件缺失或损坏，服务会明确报错。可用 `GLADS_GOLDEN20_ZIP` 指定其他存放位置；可用 `GLADS_REVIEW_DB` 指定本地数据库路径。

## 第一阶段范围

- 工作台：20 例切换与筛选；双图、宫格、卷帘；同步缩放和平移；精确执行掩码叠加；像素差异；全屏检查。
- 来源：按交付包清单显示案例、候选哈希、掩码外改动记录和风险。第 6、9 例缺少 R12，界面明确标为“未生成”。
- 人工记录：填写复核人、定位批注、判断理由；选择 `approve`、`reject`、`secondary_repair_required` 或 `defer_expert`。高风险案例不能直接采纳。所有已提交结论按时间追加，旧记录保留。
- 导出：ZIP 包含 `reviews.csv`、`annotations.csv`、`case_index.json` 和来源说明。图片仍由校验过的原始交付包保存。
- 框架：首页、素材池、审核、设置仅保留导航和留白页面，供后续成员独立开发。

人工记录存于 `data/reviews.sqlite3`；未提交的表单暂存于当前浏览器。请备份数据库文件。服务默认只监听本机，不提供多人登录或远程部署。

## 重要边界

Golden20 候选是 Big-LaMa **参考结果**，不是学生自训修复模型的输出，也不是历史原貌真值。交付包没有学生最终修复权重 `best.pt`；要让新上传图像经过正式检测、融合与修复，仍需算法组完成模型训练、验收与可调用环境。系统里的人工 `approve` 只表示对这张参考候选的当前视觉判断，不表示学生模型通过验收。

## 协作结构

| 位置                        | 职责                                                       |
| --------------------------- | ---------------------------------------------------------- |
| `server/app.py`             | 读取并校验参考包、提供只读图片、保存 SQLite 人工记录、导出 |
| `src/services/reviewApi.js` | 前端与本地服务的唯一请求入口                               |
| `src/features/workbench/`   | 工作台状态、图像检查和各独立面板                           |
| `src/components/UI.jsx`     | 最小共享面板、弹窗与状态标记                               |
| `src/pages/Placeholder.jsx` | 其他一级页面的留白容器                                     |
| `src/main.jsx`              | 一级页面导航                                               |
| `docs/architecture.md`      | 数据来源、扩展边界与算法接入条件                           |

新算法结果接入时，先在服务层新增结果来源及映射，再复用图像检查组件。不要让前端直接调用算法脚本、修改交付包或读取任意本机路径。
