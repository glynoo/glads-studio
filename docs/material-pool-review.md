## 发现与处理

- 洞窟选择没有更新 URL，素材池已挂载时也不响应图片链接参数。改为由 hash 统一驱动洞窟、图片和上传弹窗状态，导航监听随组件卸载清理。
- 上传到其他洞窟时，图片可能被当前洞窟或搜索条件隐藏。保存成功后清除搜索并进入新素材所属洞窟和详情。
- 搜索无结果显示“没有上传图像”，容易误解为文件丢失。新增独立搜索空状态和清除搜索，搜索同时覆盖备注。
- 列表读取失败没有恢复入口，还显示首次上传提示。总览和详情增加重新读取入口，并区分加载、读取错误与真实空列表。
- 来源和备注只能在上传时填写。新增编辑入口与数据库保存接口；仅上传人可以修改，服务端独立校验归属和字段长度。
- 关联修复结果仅按文件名匹配。改为核对上传原图与参考原图 SHA256，避免同名不同图误关联；未匹配的上传图不展示参考修复结果。
- Windows 启动依赖 `python3` 和 Unix Vite 执行文件。改为按平台选择 Python，通过当前 Node 执行 Vite，并处理启动失败；API 测试使用相同的跨平台解释器选择。
- SQLite 的 `with` 原来只提交事务，没有关闭连接，导致 Windows 文件占用和测试清理失败。新增事务上下文，结束后显式关闭，并验证异常回滚。
- 长文件名、洞窟名称及多行备注增加换行处理；手机表单与搜索输入调整为 16px；修改样式限定在素材池内。

- 生产构建成功：1601 个模块转换完成。
