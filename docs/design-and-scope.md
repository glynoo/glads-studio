# 第一阶段设计范围

按论文的“任务上下文—图像证据—判断依据—决策操作”组织工作台，沿用用户确认的六个可分离模块：左侧案例导航与复核进度，中部图像比较与定位批注，右侧案例信息与人工判断。全屏检查收起外围模块，保留必要的身份和操作。

当前实际数据来自 GLADS v1.0 交付包的 Golden20 参考案例。数据与持久化逻辑放在本地服务，界面组件只消费结构化案例与图片 URL。第一步仅完成工作台，其他入口留白；存档标签 `workbench-v0.1.0` 保留这一状态。第二步按 [page-expansion.md](page-expansion.md) 独立完成其他四页。

详细的来源、边界和后续接入点见 [architecture.md](architecture.md)。
